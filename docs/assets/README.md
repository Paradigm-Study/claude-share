# Demo assets

`invitation-demo.png` and `invitation-demo.mp4` show a teammate's invitation arriving above the composer in Claude Desktop. The clip is eight seconds long; it does not show completing the join.

These assets come from the Shared Sessions native team V5 demo. The demo uses fictional Alex, Leo, Maya and Sam on one Mac. Native Desktop and terminal recordings were edited together; they are not a synchronized recording of two physical machines. The overview shows the location of the enlarged UI in its original window. The example task belongs to the fictional Fieldnotes project.

The [90-second demo](https://x.com/thescottfan/status/2109815791441072416) was published separately. These files contain the invitation excerpt and a still from it.
